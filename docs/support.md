# BunnyBar Support

BunnyBar is a macOS menu-bar companion for macOS 13 Ventura and later.

## Basic use

1. Launch BunnyBar. A rabbit appears along the top edge of each connected display.
2. Click the rabbit icon in the menu bar to view CPU, memory, motion, and speed information.
3. Use **Hide Bunny** or **Show Bunny** to control the overlay.
4. Enable **Launch at Login** if you want macOS to start BunnyBar automatically.
5. Choose **Quit BunnyBar** to stop the app completely.

## Troubleshooting

- If the rabbit is hidden, open the menu-bar menu and choose **Show Bunny**.
- If macOS requires approval for Launch at Login, follow the link to **System Settings > General > Login Items**.
- If a display was connected or disconnected, relaunch BunnyBar if the overlay does not rebuild automatically.
- BunnyBar requires a logged-in graphical macOS session and does not display a Dock icon.

# BunnyBar サポート

BunnyBarはmacOS 13 Ventura以降で動作するメニューバーアプリです。

## 基本的な使い方

1. BunnyBarを起動すると、接続中の各ディスプレイ上端にうさぎが現れます。
2. メニューバーのうさぎアイコンをクリックすると、CPU、メモリ、動作状態、速度を確認できます。
3. **うさぎを隠す／表示する**でオーバーレイを切り替えます。
4. 必要に応じて**ログイン時に起動**を有効にします。
5. 完全に終了するには**BunnyBarを終了**を選びます。

不具合や要望は[GitHub Issues](https://github.com/hiroyannnn/BunnyBar/issues/new/choose)へお願いします。macOSのバージョンとMacのモデルを添え、パスワードや個人情報は投稿しないでください。
