BunnyBar サポート

BunnyBarはmacOS 13 Ventura以降で動作するメニューバーアプリです。

基本的な使い方

  1. BunnyBarを起動すると、接続中の各ディスプレイ上端にうさぎが現れます。
  2. メニューバーのうさぎアイコンをクリックし、英語UIで状態を確認・操作します。
  3. Hide Bunny または Show Bunny でオーバーレイを切り替えます。
  4. 必要に応じて Launch at Login を有効にできます。
  5. 完全に終了するには Quit BunnyBar を選びます。
メニューバーに表示される英語UI
表示内容
CPU …CPU使用率と負荷状態
Rabbit state …うさぎの動作状態
Next hop tempo …次のホップのテンポ
Memory …メモリ使用率（取得できない場合は unavailable）
Launch at Loginログイン時に起動
Hide Bunny / Show Bunnyオーバーレイを隠す／表示する
Quit BunnyBarアプリを終了

トラブルシューティング

  • うさぎが見えない場合は、メニューバーから Show Bunny を選んでください。
  • ディスプレイを接続・切断したあと表示が更新されない場合は、BunnyBarを再起動してください。
  • BunnyBarはDockにアイコンを表示しません。操作はメニューバーから行います。

お問い合わせ

不具合やご要望はGitHub Issuesへお寄せください。macOSのバージョンとMacのモデルを添え、パスワードや個人情報は投稿しないでください。

English support

Launch BunnyBar to show a rabbit along the top edge of each connected display. Use the menu-bar item to view CPU, memory, motion, and speed information, hide or show the rabbit, manage Launch at Login, or quit the app.

For bugs and feature requests, visit BunnyBar Issues. Include your macOS version and Mac model, but do not post passwords or private information.
