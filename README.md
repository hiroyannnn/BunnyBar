A tiny rabbit running freely on the macOS menu bar — a delightful companion on your screen.

## Features
- 🐰 Monochrome rabbit animation above your menu bar
- 🎯 Transparent, lightweight, non-intrusive overlay
- 📌 Works across Spaces and fullscreen
- 🖱️ Right-click to quit

### Manual
1. Download the latest release from [GitHub Releases](https://github.com/hiroyannnn/BunnyBar/releases)
2. Unzip the archive
3. Open `BunnyBar.app` and drag it to your Applications folder

## How to Quit
Right-click on the rabbit or the top strip → **Quit BunnyBar**

## Uninstall
1. Quit BunnyBar (right-click → **Quit BunnyBar**)
2. Delete `BunnyBar.app` from your Applications folder

## Troubleshooting
- **macOS blocks the app**  
  Open **System Settings → Privacy & Security** and allow BunnyBar.
- **The rabbit is not visible on multi-monitor setup**  
  Currently displays on the main screen only (multi-monitor support planned).
